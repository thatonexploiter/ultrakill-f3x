# ultrakill-f3x
A Ultrakill script for F3X!

# Main Features
- a Loader GUI that is SmileOS-Styled
- Machine Selection
- Smart Anti-Griefing integrated system (enabled by default, you can change that on the Anti-grief button on the loader, i hate griefers, if you're one.. well this script is not for you.)
- Machines have actual good models and custom, well made procedural animations

- V1
- V2
- Minos prime
